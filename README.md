# study-buddy

Study Buddy on lihtne ja kasutajasõbralik veebileht, mis on loodud HTML-i ja SASS-i abil.
Lehe eesmärk on jagada õppimise nippe ning pakkuda kasutajatele võimalust lisada oma nõuandeid või liituda kogukonnaga.

Projekt on tehtud õppetöö raames ning keskendub semantilisele HTML-ile ja SASS-i kasutamisele.

Tööjaotus:

Ralf Soiela – JavaScript ja HTML (struktuur, meediaelemendid: logo, favicon, pildid)

German Vesi – SASS/CSS (kujundus, mobiilivaade / responsive design)
